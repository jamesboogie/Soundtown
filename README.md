# Soundtown

SoundByte retro soundboard: six 8-bit sound cues in a static web page.

Live site: https://jamesboogie.github.io/Soundtown/

## Run locally

```
npm start
```

Then open http://localhost:3000.

## Deploy

GitHub Pages serves the `docs/` folder on `main` (Settings → Pages → Deploy from a branch → `main` / `/docs`).

Sound effects are CC0; see `CREDITS.md`.
