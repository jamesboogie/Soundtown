# SoundByte asset credits

## Included sound effects

SoundByte includes six curated WAV effects from **The Essential Retro Video Game Sound Effects Collection [512 sounds]** by **Juhani Junkala** (published by SubspaceAudio on OpenGameArt).

| SoundByte cue | Included file | Source category |
| --- | --- | --- |
| Coin Drop | `sfx_coin_single4.wav` | General Sounds / Coins |
| Coin Burst | `sfx_coin_cluster6.wav` | General Sounds / Coins |
| Cursor Zip | `sfx_menu_move2.wav` | General Sounds / Menu Sounds |
| Level Clear | `sfx_menu_select3.wav` | General Sounds / Menu Sounds |
| Arcade Blast | `sfx_exp_shortest_hard4.wav` | Explosions / Shortest |
| Alert Loop | `sfx_alarm_loop5.wav` | General Sounds / Alarms / Alarms |

- **Source page:** [512 Sound Effects (8-bit style) on OpenGameArt](https://opengameart.org/content/512-sound-effects-8-bit-style)

- **License note:** CC0 allows use, adaptation, and redistribution without a legal attribution requirement. This project preserves attribution and source links as a courtesy and for clarity.

No sound effects from commercial video games are included.
